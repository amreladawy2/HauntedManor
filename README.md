# Haunted Manor

DMET 502 Computer Graphics, Winter 2026 — Project 2: 3D World Navigation.

An abandoned Victorian manor at night. Explore two rooms, the **Library** and the **Nursery Bedroom**,
inspect what is left behind, and toggle the horror when you dare.

**Goal:** escape the manor.
1. Investigate the four strange objects in the Library. Once all four are done, a map appears on the desk.
2. Take the map and read it (M). It marks where a key is hidden in the Nursery.
3. Pick up the key and answer the riddle.
4. A right answer sets you free. A wrong answer brings the doll.

## Build (Windows, MSYS2 UCRT64)

Packages: `mingw-w64-ucrt-x86_64-{gcc,cmake,ninja,glfw,glew,glm,assimp,stb}`.

```
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
build/HauntedManor.exe
```

The game finds `assets/` and `shaders/` by searching the working directory, its parents, and the source
folder baked in at build time, so it runs from the build folder or the project root.

### Regenerating assets

All models, textures and sounds are generated by scripts (Python 3 + Pillow):

```
py -3.10 tools/gen_textures.py
py -3.10 tools/gen_models.py
py -3.10 tools/gen_sounds.py
```

Any `.obj`/`.fbx`/`.gltf` dropped into `assets/models/` with the same id is loaded through Assimp instead.

### Screenshot tour (testing)

```
build/HauntedManor.exe --shots out_dir
```

Plays a scripted tour of both rooms and saves a PNG at each step: every camera view, every interaction (triggered
through the real E-key range and view-angle test) and horror mode. It prints PASS/FAIL for each check: E does nothing
out of range, each object triggers, and each object returns to its initial state.

Layout check: `tools/check_layout.cpp` (build command in its first lines).

### Submission

Zip `src/`, `shaders/`, `tools/`, `CMakeLists.txt` and this README. The shaders are separate files; the game
shows nothing without them.

## Controls

| Key | Action |
|---|---|
| W / S, A / D | Move forward / back, strafe left / right |
| Arrow keys | Turn the view left / right / up / down |
| Left Shift | Run |
| E | Interact with the nearest object (must be in its range and in view) |
| 1 / 2 / 3 or click | Top / Front / Side view (you can keep walking) |
| 4 or click | Perspective: first-person / third-person; returns from a fixed view |
| TAB, F1, F2 | Switch scene (toggle, Library, Bedroom) |
| F | Flashlight on / off |
| Z / X | Moonlight dimmer / brighter |
| C / V | Fire, candles and lamps dimmer / brighter |
| B / N | Flashlight dimmer / brighter |
| H | Horror mode |
| M | Read the map (once you have found it) |
| J | Jump scare |
| 1–4 or click | Pick a riddle answer (while the riddle is open); Esc closes it |
| Enter | Keep exploring after the win screen |
| I | Show / hide controls |
| ESC | Quit |

## Requirement map

| Requirement | Where |
|---|---|
| Imported, textured models with own model matrix | `src/Model.cpp` (Assimp), `SceneObject::modelMatrix` in `src/Scene.cpp` |
| Two scenes, >= 8 unique models each, switch any time | `buildLibrary` / `buildBedroom` in `src/Scene.cpp`; TAB/F1/F2 in `src/Game.cpp` |
| Ground surface and boundaries | room shell + bounds clamp in `src/Game.cpp` / `src/Player.cpp` |
| Time-based keyboard navigation | `src/Player.cpp` |
| 4 interactive objects per scene, own range, angle and camera pose; reset after | `Interaction` in `src/Scene.h`, state machine in `src/Game.cpp` |
| Rotation, swing, translation, scaling and colour animations | `AnimFlags` in `src/Scene.h` |
| Player model, first- and third-person cameras | `src/Player.cpp`, `src/Camera.cpp` |
| Top / Front / Side / Perspective buttons (keys + mouse) | `src/Hud.cpp`, `src/Game.cpp` |
| Directional, point and spot lights in shaders; key-driven and automatic changes | `shaders/scene.frag`, `src/Lighting.cpp`, `src/Game.cpp` |
| Horror effect: camera shake, light effects, self-animating objects | `src/Game.cpp`, `shaders/scene.frag` |
| Bonus: sound effects | `src/Audio.cpp`, `assets/sounds/` |
| OpenGL 4.6 core profile, own shaders | `src/main.cpp`, `shaders/` |
